# Lab 10: Introduction to Machine Translation (MT)

This lab explores Machine Translation using TensorFlow and an Encoder-Decoder LSTM model to translate English sentences into French. I explained the Embedding, Encoder LSTM, Decoder LSTM, and softmax layers, selected 10,000 short English-French sentence pairs with common words, and used tokenization and padding to prepare the data. I trained the model for up to 30 epochs with EarlyStopping, evaluated its accuracy, and compared predicted French translations with the correct sentences.
